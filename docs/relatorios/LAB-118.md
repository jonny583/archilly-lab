## 4 · A régua, e os dois lados

**(a) Todo relatório tem uma ligação.** Relatório = `docs/relatorios/<nome>.md` (só o nível de cima). Ligação =
`[texto](alvo)` fora de crases e de bloco cercado, resolvida pela pasta do índice.

| caso | resultado |
|---|---|
| o índice de antes (sem as seis) | **reprova**, nomeando os seis |
| a ligação com `./` ou âncora `#x` | passa |
| o nome entre crases, **sem** ligação | **reprova** — citar não é indexar |
| `../docs/relatorios/A.md` | passa (resolve para o mesmo lugar) |
| `../relatorios/A.md` | reprova (resolve para outra raiz) |
| prova (`docs/provas/…`) e subpasta de `relatorios/` | não são relatório |

**(b) A linha da página que muda a cada rodada.** As sete: `ONDE_PARAMOS.md`, `caixa-de-entrada/COMO_FUNCIONA.md`,
`prompts/FILA.md`, `DECISOES.md`, `PENDENCIAS_JONNY.md`, `relatorios/BALANCOS.md`, `relatorios/RECADOS.md`. Lê-se a
linha de tabela cujo **primeiro campo** liga para uma delas; tira-se o trecho entre crases, as ligações e a
citação (`LAB-NN`, `LF-…`, `D123`, `item 003`, `§1-B`); sobra algarismo → reprova; sobra *"hoje:"* (com ou sem
negrito) → reprova.

| caso | resultado |
|---|---|
| *"72 decisões"*, *"a fila de 19/09"*, *"Hoje: …"* | **reprovam** (as três de 16/10) |
| *"(LAB-06)"*, *"A D61"*, *"§1-B"*, *"item 030"* | passam — citação é ponteiro, não estado |
| ***"Onde estamos hoje"*** (sem dois-pontos) | **passa** — o caso válido que quase parece inválido |
| *"**Hoje**: a D99"* | reprova |
| a mesma frase numa linha de **outra** página que só cita a `DECISOES.md` | não é lida — é de outro dono |
| página com zero linhas, ou duas | **reprova** — ausência não aprova |

**Mutações no módulo**, cada uma rodada contra a trava e desfeita:

| mutação | travas que caem |
|---|---|
| comparar o alvo cru, sem resolver pela pasta | 5 |
| relatório em qualquer profundidade | 3 |

| sem tirar a citação | 3 |
| sem o sinal do algarismo | 1 |
| *"hoje"* sem exigir os dois-pontos | 3 |
| *"hoje"* sem atravessar o negrito | 1 |
| a página lida em qualquer campo da linha | 1 |
| sem a conta de linhas (ausência aprova) | 1 |
