## 4 · O que a régua cobra

| problema | quando |
|---|---|
| `cabecalho-ilegivel` | a página sem `**Última atualização:** … **Último prompt executado:** LAB-NN` — não é verde |
| `recados-sem-prompt` | o `RECADOS.md` sem nenhum título de prompt |
| `prompt-diferente` | o prompt do cabeçalho não é o último título de prompt — **o defeito do `76bfdcd`** |
| `item-diferente` | o item do cabeçalho não é o do primeiro recado desse prompt |
| `data-anterior-ao-recado` | a data do cabeçalho antes do título desse prompt (depois pode: o 2º despertador do LAB-95) |
| `corrente-fora-de-ordem` | um elo *"antes dele o X"* que não é o próximo prompt da sequência sem repetição |

Prompt do cabeçalho que o `RECADOS.md` não tem gera **um** problema, não um por elo.

## 6 · As escolhas, e as alternativas descartadas

- **O "último prompt" é o último título de PROMPT, não o último título.** Num disparo em vazio o título é de
  classe, e o cabeçalho que fica no último prompt está certo — medido: nos três disparos em vazio de 09 e 10/10 o
  cabeçalho ficou no LAB-77, LAB-78 e LAB-80, e a régua os aprova.
- **Cobrar o texto de cada elo — não.** É relato; o relato mora no relatório.
- **Cobrar a hora — não.** O título do recado não tem hora; não há com o que comparar.
- **Exigir a corrente até o começo — não.** Hoje ela para no LAB-96, e encurtar não afirma nada falso.
- **Pôr a régua dentro de uma trava que já lê o `ONDE_PARAMOS.md` (a da conta dos disparos) — não.** É outro
  objeto (a linha de cabeçalho, contra outra página); módulo próprio, e o trabalho sem clones ganha um arquivo.
- **Reescrever o `76bfdcd` — não.** É história; está medida aqui e na D354.
